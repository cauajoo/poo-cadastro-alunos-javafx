# Sistema de Cadastro de Alunos (JavaFX)

> **P2 · 2026.1** · Avaliação da disciplina de Programação Orientada a Objetos

Aplicação desktop em Java com interface gráfica em JavaFX (telas feitas no Scene Builder) para cadastrar,
consultar, editar e remover alunos, aplicando os conceitos de orientação a objetos.

## Funcionalidades
- Tela de login
- Cadastro de alunos com notas
- Consulta, edição e remoção de alunos

## Tecnologias
Java 21 · JavaFX 21 (FXML) · Scene Builder · Maven

## Como executar
1. Abra a pasta do projeto no IntelliJ IDEA (ou outra IDE com suporte a Maven).
2. Aguarde o download das dependências do Maven.
3. Execute a classe `br.com.poo.registrationsystem.Main`.

## Estrutura
```
src/main/java/br/com/poo/registrationsystem/   código Java (Main, controllers, modelos)
src/main/resources/br/com/poo/registrationsystem/   telas FXML e CSS
src/main/resources/img/   imagens da interface
```
